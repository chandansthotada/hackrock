Smart voting system 

This project presents a secure and efficient Smart Voting System that integrates password-based authentication with face recognition technology to ensure reliable and fraud-free voting. 
The primary goal of the system is to prevent impersonation, duplicate votes, and unauthorized access during the voting process.
The system operates in two main phases: voter registration and voting. During registration, each voter provides their Aadhaar number, a secure password, and their facial image captured using a webcam. This data is securely stored and linked to the voter's identity.
The password provides an initial layer of authentication, while face recognition acts as a biometric second factor to confirm the voter's identity.
During the voting phase, the voter must log in using their Aadhaar number and password, after which the system uses real-time face recognition to verify that the voter is genuine. 
Upon successful authentication, the voter is presented with a list of candidates and can cast their vote. Each vote is securely stored, and the system prevents multiple voting attempts by the same individual.
The system also includes features like voice confirmation after voting and SMS alerts (via Pushover) to notify voters of successful registration and vote casting.
This enhances transparency and keeps the voter informed throughout the process.

Overall, the Smart Voting System ensures a safe, user-friendly, and tamper-resistant election process suitable for digital governance, educational institutions, and private organizations.
